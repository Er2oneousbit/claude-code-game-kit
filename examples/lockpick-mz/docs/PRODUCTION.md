# Production

> Not started. `/next-tier` fills this in when the vertical slice is done and the game moves to the MVP / Release tier
> (the greenlight). Until then, scope comes from `docs/GDD.md` "Current tier" and `docs/ROADMAP.md`.
> Progress is counted in items and content, never dates. Claude reads the Backlog at session start once this is live.

## Milestones (scope, no dates)
| Milestone | Exit criteria | Status |
|---|---|---|
| Alpha | Every MVP system is in and playable (placeholder content is fine); a playtest of the whole loop | |
| Beta | All MVP content is in; no known crash; saves and settings work; a playtest by someone new to the game | |
| Release candidate | `/release-check` green (SOP-06) | |

Each milestone ends with a playtest (`/playtest-report`). If a system stops being fun, mark it in the Backlog as
`back to prototyping` and treat it as a toy until it is fun again.

## Backlog

`done`, `cut`, `back to prototyping`. New ideas that serve a pillar land here with a size; the owner decides if they go
into a milestone. Ideas outside the pillars go to the ROADMAP Parking lot.
