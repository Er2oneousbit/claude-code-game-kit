# Learning, reference, marketing and release

Books, docs, talks, and where to show the game.

> **Read this caveat.** Written from general knowledge plus video notes, not live-checked. Sites change terms, go offline, or rename
> licenses. The license that matters is the one on the **specific asset page on the day you download it**. Save the license text in
> `docs/licenses/` and log the asset in `docs/ASSET_LOG.md` via `/asset-intake`. Anything marked **(verify)** is the most likely to have changed.

## Learning and reference
- *Game Programming Patterns* (free online, Robert Nystrom). Game loop, state, object pool, command.
- *Game Feel* (Steve Swink) and the talk "Juice it or Lose it". For making things feel good.
- Godot docs (`docs.godotengine.org`), Unreal docs (`dev.epicgames.com/documentation`), Lazy Foo SDL2 tutorials,
  SDL wiki (`wiki.libsdl.org`), Learn OpenGL, Handmade Hero for low-level inspiration.
- Bevy: the official examples (`bevy.org/examples`, each one matches a release), docs.rs for the exact version,
  the migration guides on `bevy.org/learn/migration-guides` (one per release), and the Bevy Cheat Book (community; check
  which version a page covers).
- GDC Vault and GDC YouTube channel for postmortems.
- Design: *The Art of Game Design: A Book of Lenses*, Mark Brown's Game Maker's Toolkit videos.

## Marketing and release
- Steamworks docs and the Steam page checklist. **(verify current requirements)**
- `itch.io` for demos and early feedback. Devlogs on Mastodon, Bluesky, YouTube, Discord communities.
- Press kit: logo, 5 to 10 screenshots, GIFs, trailer, one-page fact sheet.
